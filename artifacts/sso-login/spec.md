## 개요
앱 접속 시 로그인이 필수(게이트)가 된다. 로그인하지 않은 상태로는 주유소 검색 화면(위치 권한, 리스트, 지도) 자체에 접근할 수 없고, 카카오·네이버·구글·Apple 중 하나로 로그인해야 들어갈 수 있다. 로그인 성공 후에는 계정에 저장된 지도 provider(카카오맵·네이버지도·티맵)가 있으면 곧바로 그 provider로 주유소 검색 화면에 진입하고, 아직 한 번도 정한 적 없으면(최초 로그인) 지도 provider를 고르는 화면이 한 번 뜬다. 로그인하면 주유소를 즐겨찾기에 저장할 수 있고, 유종·브랜드 필터 설정도 계정에 동기화되어 다른 기기에서도 유지된다.

## 범위

### 포함
- 앱 진입 시(로그인 안 된 상태) 로그인 화면이 먼저 뜬다 — 주유소 검색 화면은 로그인 전에는 전혀 보이지 않는다
- 카카오·네이버·구글·Apple 4개 provider를 통한 로그인
- 로그인 성공 후, 계정에 지도 provider가 이미 저장돼 있으면 곧바로 그 provider로 주유소 검색 화면에 진입
- 로그인 성공 후, 계정에 지도 provider가 아직 한 번도 저장된 적 없으면 지도 provider(카카오맵·네이버지도·티맵) 선택 화면이 한 번 뜨고, 고르면 그 값이 계정에 저장되며 주유소 검색 화면에 진입
- 로그인 후 언제든 기존 설정 화면(톱니바퀴)에서 지도 provider를 다시 바꿀 수 있다 — 이 변경도 계정에 저장됨(기존 기능 유지, 최초 선택 화면은 계정에 값이 하나도 없을 때 한 번만 등장)
- 로그아웃하면 로그인 화면으로 돌아가고, 주유소 검색 화면에는 다시 접근할 수 없다
- 로그인 후에만 사용 가능한 즐겨찾기: 결과 리스트 각 항목의 하트 아이콘으로 토글, 즐겨찾은 주유소만 모아보는 별도 목록
- 최초 로그인 시 이 기기에 저장돼 있던 유종·브랜드 필터 설정을 계정에 업로드, 이후 로그인 시(다른 기기 포함) 계정에 저장된 값이 적용됨 — 가장 최근에 로그인·변경한 기기 기준으로 덮어씀
- provider별로 별개 계정으로 취급(카카오로 만든 계정과 구글로 만든 계정은 이메일이 같아도 서로 다른 계정)

### 제외
- 비로그인 게스트 모드: 로그인이 필수 게이트로 결정되면서 완전히 제외됨(이전 논의에서는 선택 사항이었으나 이번 결정으로 대체됨)
- provider 간 계정 연결/병합: 단순함을 위해 제외, provider별 별개 계정으로 취급
- 회원 탈퇴·계정 삭제 흐름: 아직 논의되지 않음, 별도 feature로 다룸
- 다른 사용자와 즐겨찾기 목록 공유: 이번 범위 밖
- 이메일/비밀번호 등 SSO가 아닌 로그인 수단: 이번 범위는 SSO 전용

## End-to-end 검증

1. 로그인하지 않은 상태로 앱 접속 → 로그인 화면이 뜨는지 확인 (S10)
2. "카카오"로 로그인(이 계정 최초 로그인) → 지도 provider 선택 화면이 뜨는지 확인 (S11)
3. "네이버지도" 선택 → 주유소 검색 화면에 진입하고 지도가 네이버지도로 그려지는지 확인 (S12)
4. 유종을 "경유"로 바꾸고, 리스트 항목 하나에 하트를 눌러 즐겨찾기 추가 (S5 전 단계 설정, S7)
5. 즐겨찾기 목록 화면을 열어 방금 추가한 항목이 보이는지 확인 (S9)
6. 로그아웃 → 로그인 화면으로 돌아가는지 확인 (S14)
7. 같은 "카카오" 계정으로 다시 로그인 → 이번엔 지도 provider 선택 화면 없이 곧장 네이버지도 검색 화면으로 들어가고, 유종은 "경유", 즐겨찾기 목록에 방금 항목이 그대로 남아있는지 확인 (S13, S5, S7)
8. (재현 가능하면) 다른 브라우저 프로필에서 같은 계정으로 로그인해 S6(다른 기기 필터 설정 적용)을 확인

## 의존성

- 카카오·네이버·구글·Apple 각 provider의 OAuth 앱 등록과 클라이언트 ID·시크릿 발급 — 배포 전 사용자가 각 콘솔에서 직접 준비해야 함(Apple은 별도의 개발자 프로그램 등록이 추가로 필요할 수 있음)
- 계정·즐겨찾기·동기화된 설정을 저장할 서버/데이터 저장소 — 현재 앱은 완전 정적·무상태(anonymous)라 이번 feature에서 처음 필요해짐. 구체적 방식(DB 종류, 세션 관리 방식 등)은 plan.md에서 결정
- `map-provider-selection` feature 완료(계정에 동기화할 지도 provider 설정·설정 화면 토글이 이미 존재해야 함)
- `map-provider-choice`(비로그인 상태에서 최초 진입 시 지도 provider를 고르던 spec, 아직 미착수)는 이번 결정(로그인 게이트 + 로그인 후 provider 선택)과 전제가 상충함 — plan.md 단계에서 재검토·폐기 필요
