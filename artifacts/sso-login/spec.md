## 개요
메인 화면에 카카오·네이버·구글·Apple SSO 로그인을 추가한다. 로그인은 선택 사항이며 앱은 계속 비로그인 상태로도 지금과 동일하게 완전히 동작한다. 로그인하면 (1) 주유소를 즐겨찾기에 저장할 수 있는 새 기능이 열리고, (2) 지금은 이 기기에만 저장되던 유종·브랜드 필터·지도 provider 설정이 계정에 동기화되어 다른 기기에서도 유지된다.

## 범위

### 포함
- 메인 화면 설정(톱니바퀴) 아이콘 옆의 로그인/프로필 진입점
- 카카오·네이버·구글·Apple 4개 provider를 통한 로그인
- 로그인 성공 시 진입점이 프로필 표시로 전환, 그 자리에서 로그아웃 가능
- 로그인 상태에서만 사용 가능한 즐겨찾기: 결과 리스트 각 항목의 하트 아이콘으로 토글, 즐겨찾은 주유소만 모아보는 별도 목록
- 최초 로그인 시 이 기기에 저장돼 있던 유종·브랜드 필터·지도 provider 설정을 계정에 업로드
- 이후 로그인 시(다른 기기 포함) 계정에 저장된 설정이 적용됨 — 가장 최근에 로그인·변경한 기기 기준으로 덮어씀
- provider별로 별개 계정으로 취급(카카오로 만든 계정과 구글로 만든 계정은 이메일이 같아도 서로 다른 계정)

### 제외
- provider 간 계정 연결/병합: 사용자 결정 사항 — 단순함을 위해 이번 범위에서 제외, provider별 별개 계정으로 취급
- 비로그인 상태에서의 즐겨찾기: 로그인 필수로 결정됨(사용자 결정 사항)
- 회원 탈퇴·계정 삭제 흐름: 아직 논의되지 않음, 별도 feature로 다룸
- 다른 사용자와 즐겨찾기 목록 공유: 이번 범위 밖
- 이메일/비밀번호 등 SSO가 아닌 로그인 수단: 이번 범위는 SSO 전용

## 시나리오

### S1. 로그인 진입점은 비로그인 상태에서 항상 보인다
- **Given**: 로그인하지 않은 상태로 앱에 접속함(위치 권한 상태와 무관)
- **When**: 메인 화면을 본다
- **Then**
  - [ ] S1 설정 아이콘 옆에 로그인 진입점이 보인다

### S2. provider를 선택해 로그인한다
- **Given**: 로그인 진입점이 보이는 상태
- **When**: 진입점을 눌러 카카오·네이버·구글·Apple 중 하나를 선택하고 해당 provider의 인증을 완료한다
- **Then**
  - [ ] S2-1 로그인 진입점이 프로필 표시(로그인된 상태)로 바뀐다
  - [ ] S2-2 이전에 보고 있던 리스트·필터·지도 상태는 그대로 유지된다(새로고침 없이 로그인만 반영됨)

### S3. 로그인 실패 또는 취소
- **Given**: provider 인증 화면으로 이동한 상태
- **When**: 사용자가 인증을 취소하거나, provider 쪽 오류로 인증이 실패한다
- **Then**
  - [ ] S3 메인 화면으로 돌아오고, 로그인 진입점은 계속 비로그인 상태로 남는다(에러로 인해 앱의 다른 기능이 막히지 않는다)

### S4. 로그아웃
- **Given**: 로그인된 상태(프로필 표시가 보임)
- **When**: 프로필 표시를 통해 로그아웃을 실행한다
- **Then**
  - [ ] S4-1 진입점이 다시 비로그인 상태(로그인 버튼)로 바뀐다
  - [ ] S4-2 즐겨찾기 목록·하트 표시 등 로그인 전용 UI는 더 이상 보이지 않고, 리스트·필터·지도 등 기존 기능은 비로그인 상태로 계속 정상 동작한다

### S5. 최초 로그인 시 이 기기의 설정을 계정에 올린다
- **Given**: 아직 어떤 기기에서도 로그인한 적 없는 계정으로, 이 기기의 유종·브랜드 필터·지도 provider 설정이 기본값과 다르게 바뀌어 있는 상태
- **When**: 이 provider로 처음 로그인한다
- **Then**
  - [ ] S5 로그인 직후에도 이 기기의 설정(유종·브랜드 필터·지도 provider)이 그대로 유지되고, 이 값이 계정에 저장된다

### S6. 다른 기기에서 로그인하면 계정에 저장된 설정이 적용된다
- **Given**: 어떤 기기(A)에서 로그인해 유종·브랜드 필터·지도 provider 설정을 바꾼 뒤 저장된 상태
- **When**: 다른 기기(B)에서 같은 계정으로 로그인한다
- **Then**
  - [ ] S6 기기 B의 설정이 기기 A에서 마지막으로 저장된 값으로 바뀐다

### S7. 즐겨찾기 토글
- **Given**: 로그인된 상태, 결과 리스트에 주유소 항목이 보임
- **When**: 항목의 하트 아이콘을 누른다
- **Then**
  - [ ] S7-1 하트 아이콘이 즐겨찾기 상태(채워짐)로 바뀐다
  - [ ] S7-2 다시 누르면 즐겨찾기가 해제되고 하트 아이콘이 원래 상태로 돌아온다

### S8. 비로그인 상태에서는 즐겨찾기를 쓸 수 없다
- **Given**: 로그인하지 않은 상태, 결과 리스트에 주유소 항목이 보임
- **When**: 리스트를 본다
- **Then**
  - [ ] S8 하트 아이콘(즐겨찾기 토글)이 보이지 않는다

### S9. 즐겨찾기 목록 화면
- **Given**: 로그인된 상태, 즐겨찾은 주유소가 1곳 이상 있음
- **When**: 즐겨찾기 목록 진입점을 연다
- **Then**
  - [ ] S9-1 즐겨찾은 주유소만 모아서 보여준다
  - [ ] S9-2 즐겨찾은 주유소가 하나도 없으면 빈 상태 안내 문구("즐겨찾은 주유소가 없어요"(제안 기본값))가 보인다

## 불변 규칙

- [ ] INV-1 로그인 여부와 무관하게 위치 기반 주유소 검색·필터·정렬·지도 표시·길찾기는 지금과 동일하게 동작한다(로그인이 기존 익명 기능을 제한하지 않는다)
- [ ] INV-2 즐겨찾기 관련 UI(하트 아이콘, 즐겨찾기 목록)는 로그인 상태에서만 나타난다 (S7, S8, S9)

## End-to-end 검증

1. 로그인하지 않은 상태로 앱 접속 → 로그인 진입점이 보이는지 확인 (S1)
2. 진입점에서 "카카오"로 로그인 → 진입점이 프로필로 바뀌고 리스트·지도는 그대로인지 확인 (S2)
3. 유종을 "경유"로 바꾸고, 리스트 항목 하나에 하트를 눌러 즐겨찾기 추가 (S7)
4. 즐겨찾기 목록 화면을 열어 방금 추가한 항목이 보이는지 확인 (S9)
5. 로그아웃 → 진입점이 비로그인 상태로 돌아오고 하트 아이콘이 사라지는지 확인 (S4, S8)
6. 같은 "카카오" 계정으로 다시 로그인 → 유종이 "경유"로, 즐겨찾기 목록에 방금 항목이 그대로 남아있는지 확인 (S5, S7)
7. (재현 가능하면) 다른 브라우저 프로필에서 같은 계정으로 로그인해 S6(다른 기기 설정 적용)을 확인

## 의존성

- 카카오·네이버·구글·Apple 각 provider의 OAuth 앱 등록과 클라이언트 ID·시크릿 발급 — 배포 전 사용자가 각 콘솔에서 직접 준비해야 함(Apple은 별도의 개발자 프로그램 등록이 추가로 필요할 수 있음)
- 계정·즐겨찾기·동기화된 설정을 저장할 서버/데이터 저장소 — 현재 앱은 완전 정적·무상태(anonymous)라 이번 feature에서 처음 필요해짐. 구체적 방식(DB 종류, 세션 관리 방식 등)은 plan.md에서 결정
- `map-provider-selection` feature 완료(동기화 대상인 지도 provider 설정이 이미 존재해야 함)
