## 개요
사용자가 앱 최초 진입 시 지도 제공자(카카오맵 또는 네이버지도)를 선택하고, 이후 지도 렌더링과 길찾기가 선택된 제공자로 동작한다. 선택은 기기에 저장되어 재방문 시 생략되며, 결과 화면 상단 토글로 언제든 다른 제공자로 전환할 수 있다.

## 범위

### 포함
- 최초 진입 시(저장된 선택 없을 때) 위치 권한 요청보다 먼저 뜨는 지도 제공자 선택 화면
- 선택 결과를 기기에 저장, 재방문 시 선택 화면 생략하고 기존 흐름부터 시작
- 결과 화면 상단의 상시 토글로 언제든 제공자 전환 (리스트·선택 항목·위치는 유지, 지도만 다시 그려짐)
- 네이버지도로도 기존 카카오맵과 동등한 지도 기능 제공: 현재 위치 마커, 주유소 핀, 5곳 자동 줌, 리스트 선택 시 핀 강조
- 네이버지도 길찾기 연동 (선택된 주유소까지)

### 제외
- 네이버 지도 API 키 미발급·미설정 시 UI 가드레일: 카카오맵 키와 동일하게 별도 처리 없이, 배포 전 사용자가 키를 준비하는 것을 전제로 함 (의존성 항목으로만 기록)
- 티맵 등 카카오·네이버 이외의 지도/내비 제공자 추가
- 제공자별 요금·쿼터 비교 UI

## 시나리오

### S1. 최초 진입 시 제공자 선택 화면
- **Given**: 이 기기(브라우저)에서 지도 제공자를 선택해 저장한 적이 없음
- **When**: 앱에 처음 접속한다
- **Then**
  - [x] S1-1 위치 권한 프롬프트가 뜨기 전에 "카카오맵"과 "네이버지도" 중 하나를 고르는 선택 화면이 먼저 보인다
  - [x] S1-2 선택 화면에는 두 제공자 버튼만 보이고, 유종 토글·필터·리스트·지도 등 결과 화면 요소는 보이지 않는다

### S2. 제공자 선택 → 저장 및 진행
- **Given**: S1의 선택 화면이 보이는 상태
- **When**: "카카오맵" 또는 "네이버지도" 버튼을 누른다
- **Then**
  - [x] S2-1 선택 화면이 사라지고 기존 위치 권한 요청 흐름(로딩 → 결과)이 시작된다
  - [x] S2-2 선택한 제공자가 기기에 저장된다

### S3. 재방문 시 선택 화면 생략
- **Given**: 이전에 제공자를 선택해 저장한 적 있음
- **When**: 같은 브라우저로 앱에 다시 접속한다
- **Then**
  - [x] S3 선택 화면 없이 곧바로 기존 흐름(위치 권한 프롬프트 또는 이미 허용된 경우 결과)부터 시작하며, 지도는 저장된 제공자로 렌더링된다

### S4. 상단 토글로 제공자 전환
- **Given**: 결과 화면(리스트+지도)이 표시된 상태, 현재 제공자는 카카오맵
- **When**: 상단 토글에서 "네이버지도"를 선택한다
- **Then**
  - [x] S4-1 지도 영역이 네이버지도로 다시 그려지고, 리스트 항목·선택된 항목·현재 위치는 그대로 유지된다
  - [x] S4-2 이후 저장된 제공자가 네이버지도로 갱신되어, 다음 방문 시 네이버지도 기준으로 시작한다(S3과 연결)

### S5. 네이버지도 렌더링 동등성
- **Given**: 제공자가 네이버지도로 선택된 상태, 조회된 주유소 결과가 있음
- **When**: 결과 화면이 표시된다
- **Then**
  - [ ] S5-1 지도에 현재 위치가 별도 마커로 표시되고, 리스트의 모든 주유소 핀이 화면 안에 들어오도록 자동으로 줌이 조정된다
  - [ ] S5-2 리스트 항목을 탭하면 지도에서 해당 주유소 핀이 강조 표시된다

### S6. 네이버지도 길찾기
- **Given**: 제공자가 네이버지도로 선택된 상태, 결과 리스트에 주유소 항목이 보임
- **When**: 항목의 "길찾기" 버튼을 누른다
- **Then**
  - [ ] S6 새 탭(또는 새 창)으로 현재 위치에서 해당 주유소까지의 네이버지도 길찾기 화면(앱 또는 웹)이 열린다

## 불변 규칙

- [ ] INV-1 지도에 나타나는 기능(현재 위치 마커, 주유소 핀, 자동 줌, 선택 항목 강조)은 선택된 제공자(카카오맵/네이버지도)와 무관하게 동일하게 나타난다 (S5, cheap-gas-finder 기존 카카오맵 지도 판정 기준과 동등) — fake SDK 단위 테스트로는 증명됨, 실 네이버 SDK 시각 확인 대기 중(Human review)
- [x] INV-2 지도 렌더링과 길찾기 링크는 항상 현재 선택된 제공자와 일치한다 — 카카오맵 선택 중에는 카카오 지도·카카오 길찾기만, 네이버지도 선택 중에는 네이버 지도·네이버 길찾기만 열린다 (S4, S6, cheap-gas-finder 기존 카카오맵 길찾기 판정 기준과 연동)

## End-to-end 검증

1. 저장된 선택이 없는 상태로 앱 접속 → 제공자 선택 화면이 위치 권한 프롬프트보다 먼저 뜨는지 확인 (S1)
2. "네이버지도" 선택 → 선택 화면이 사라지고 위치 권한 흐름이 시작되는지 확인 (S2)
3. 위치 허용 → 결과 리스트와 네이버지도 지도(현재 위치 마커, 자동 줌)가 보이는지 확인 (S5-1)
4. 페이지를 새로고침(재방문) → 선택 화면 없이 곧바로 결과까지 진행되고 지도가 네이버지도로 뜨는지 확인 (S3)
5. 리스트 항목 하나를 탭 → 네이버지도에서 해당 핀이 강조되는지 확인 (S5-2)
6. 해당 항목의 "길찾기" 클릭 → 새 탭에 네이버지도 길찾기가 열리는지 확인 (S6)
7. 상단 토글에서 "카카오맵"으로 전환 → 리스트·선택 상태는 유지된 채 지도만 카카오맵으로 바뀌는지 확인 (S4)
8. 다시 새로고침 → 카카오맵 기준으로 곧바로 시작되는지 확인 (S4-2, S3)
9. 카카오맵 상태에서 길찾기 클릭 → 새 탭에 카카오맵 길찾기가 열리는지 확인 (INV-2, cheap-gas-finder 기존 카카오맵 길찾기 판정 기준과 연동)

## 의존성

- `cheap-gas-finder` feature 완료 (위치 권한 → 결과 흐름, 기존 카카오맵 연동)
- 네이버 지도 API 키(NCP 콘솔에서 발급하는 `ncpKeyId`) — 배포 전 사용자가 직접 발급해 설정해야 함 (카카오맵 키와 동일한 패턴, 미발급 시 별도 UI 처리 없음)
- 카카오맵 JavaScript API 키 (기존 의존성 유지)
- 브라우저 localStorage 지원 환경
