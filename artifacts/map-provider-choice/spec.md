> **[사용자 결정, 2026-08-24]** 사용자가 "유효 부분만 유지"를 선택했다. 아래 시나리오를 개별 검토한 결과, 이 spec이 다루려던 동작은 이미 다른 세 feature(`sso-login`, `map-provider-selection`, `cheap-gas-finder`)가 provider 중립적으로 구현·검증을 마쳤고, 이 spec만의 고유한 남은 범위는 없었다. 그래서 전체 시나리오를 개별 사유와 함께 취소선 처리했다 — 각 항목이 어디로, 왜 흡수됐는지는 아래 각 시나리오 옆에 남긴다. 이 문서는 더 이상 미착수 작업 목록이 아니라 결정 이력으로만 유지한다.

## 개요
사용자가 앱 최초 진입 시 지도 제공자(카카오맵 또는 네이버지도)를 선택하고, 이후 지도 렌더링과 길찾기가 선택된 제공자로 동작한다. 선택은 기기에 저장되어 재방문 시 생략되며, 결과 화면 상단 토글로 언제든 다른 제공자로 전환할 수 있다.

## 범위

### 포함
- 최초 진입 시(저장된 선택 없을 때) 위치 권한 요청보다 먼저 뜨는 지도 제공자 선택 화면
- 선택 결과를 기기에 저장, 재방문 시 선택 화면 생략하고 기존 흐름부터 시작
- 결과 화면 상단의 상시 토글로 언제든 제공자 전환 (리스트·선택 항목·위치는 유지, 지도만 다시 그려짐)
- 네이버지도로도 기존 카카오맵과 동등한 지도 기능 제공: 현재 위치 마커, 주유소 핀, 5곳 자동 줌, 리스트 선택 시 핀 강조
- 네이버지도 길찾기 연동 (선택된 주유소까지)

### 제외
- 네이버 지도 API 키 미발급·미설정 시 UI 가드레일: 카카오맵 키와 동일하게 별도 처리 없이, 배포 전 사용자가 키를 준비하는 것을 전제로 함 (의존성 항목으로만 기록)
- 티맵 등 카카오·네이버 이외의 지도/내비 제공자 추가
- 제공자별 요금·쿼터 비교 UI
