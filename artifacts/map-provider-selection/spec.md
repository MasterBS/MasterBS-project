## 개요
`cheap-gas-finder`의 지도 표시와 길찾기가 카카오맵 하나로 고정되어 있던 것을, 사용자가 카카오맵과 네이버지도 중 원하는 지도 provider를 설정에서 선택할 수 있도록 확장한다. 선택은 기기에 저장되어 다음 방문에도 유지되고, 지도 표시·길찾기 링크 양쪽에 동시에 적용된다.

## 범위

### 포함
- 설정 시트/메뉴를 통한 provider(카카오맵/네이버지도) 선택 UI
- 선택한 provider의 기기 저장(다음 방문에도 유지)
- 선택에 따라 지도 렌더링과 리스트의 "길찾기" 링크가 함께 전환
- 결과가 이미 표시된 상태에서 전환 시, 새로고침 없이 같은 위치·마커로 즉시 지도 교체
- 선택된 provider의 지도 SDK 로드 실패 시 에러 안내

### 제외
- 카카오맵·네이버지도 외 제3 provider(구글맵 등) 지원: 이번 범위 밖
- provider별 마커 디자인·지도 스타일 커스터마이징: 기존 시각 언어를 그대로 재사용
- SDK 로드 실패 시 다른 provider로의 자동 전환: 사용자가 설정에서 직접 바꾸도록 함 (사용자 결정 사항)
- 지도 표시와 길찾기를 서로 다른 provider로 독립 설정: 하나의 선택이 양쪽에 함께 적용됨 (사용자 결정 사항)

## 시나리오

### S1. 설정에서 provider 전환
- **Given**: 결과 리스트와 지도가 표시된 상태, 현재 provider는 네이버지도(기본값)
- **When**: 설정 진입점을 열고 "카카오맵"을 선택한다
- **Then**
  - [x] S1-1 설정 화면이 닫히고, 새로고침 없이 지도가 즉시 카카오맵으로 교체된다
  - [x] S1-2 교체된 지도에도 기존과 동일한 현재 위치 마커와 주유소 핀이 표시되고, 모든 핀이 화면 안에 들어오도록 자동으로 줌이 조정된다

### S2. 길찾기가 선택된 provider를 따른다
- **Given**: 결과 리스트에 항목이 보이는 상태
- **When**: 항목의 "길찾기" 버튼을 누른다
- **Then**
  - [x] S2 현재 설정된 provider가 카카오맵이면 새 탭에 카카오맵 길찾기 화면이, 네이버지도이면 새 탭에 네이버지도 길찾기 화면이 열린다

### S3. 최초 방문 기본값
- **Given**: 이 기기에 저장된 provider 선택 기록이 없는 최초 방문
- **When**: 앱을 연다
- **Then**
  - [x] S3 지도 표시와 길찾기 링크 모두 네이버지도가 기본값으로 적용된다

### S4. 선택 지속성
- **Given**: 설정에서 카카오맵으로 전환한 상태
- **When**: 페이지를 새로고침한다
- **Then**
  - [x] S4 새로고침 후에도 지도 표시와 길찾기 링크 모두 카카오맵으로 유지된다

### S5. 지도 SDK 로드 실패
- **Given**: 선택된 provider의 지도 SDK 로드가 실패하는 상태(키 미설정, 도메인 미등록 등)
- **When**: 지도 영역이 렌더링을 시도한다
- **Then**
  - [x] S5-1 지도 영역에 "지도를 불러오지 못했어요. 다시 시도해주세요"(제안 기본값) 안내와 "다시 시도" 버튼이 표시된다
  - [x] S5-2 다른 provider로 자동 전환되지 않으며, 리스트(순위·가격·거리)는 정상적으로 계속 표시된다

### S6. 설정 진입점
- **Given**: 앱이 로드된 상태
- **When**: 사용자가 화면을 본다
- **Then**
  - [x] S6 화면에 항상 "설정" 진입점이 보이고, 열면 현재 선택된 provider가 표시된 선택 화면(시트)이 나타난다

## 불변 규칙

- [x] INV-1 지도에 표시되는 현재 위치 마커·주유소 핀의 개수와 위치는 선택된 provider와 무관하게 동일하다 (S1, S3, S4)

## End-to-end 검증

1. 저장된 설정이 없는 상태로 앱을 처음 실행 → 지도가 네이버지도로 표시되는지 확인 (S3)
2. 설정 진입점을 열어 현재 선택값이 "네이버지도"로 표시되는지 확인 후 "카카오맵"으로 전환 (S6)
3. 전환 즉시 새로고침 없이 지도가 카카오맵으로 바뀌고, 같은 현재 위치 마커·주유소 핀이 화면 안에 들어오는지 확인 (S1, INV-1)
4. 리스트 항목의 "길찾기" 클릭 → 새 탭에 카카오맵 길찾기 화면이 열리는지 확인 (S2)
5. 페이지 새로고침 → 지도와 길찾기가 여전히 카카오맵으로 유지되는지 확인 (S4)
6. (환경상 재현이 필요하면 별도로) 선택된 provider의 SDK 키를 제거하거나 도메인 미등록 상태를 재현해 에러 안내·재시도 버튼과, 그 상태에서도 리스트는 정상 표시되는지 확인 (S5)

## 의존성

- 네이버 클라우드 플랫폼(NCP) Maps API Client ID 발급 및 서비스 URL(도메인) 등록 (사용자가 NCP 콘솔에서 직접 진행 필요)
- 카카오맵 JavaScript API 키 (기존 `cheap-gas-finder`에서 이미 사용 중)
- `cheap-gas-finder/spec.md`의 S6(및 개요·범위 서술)은 "카카오맵" 전제로 쓰여 있어, 이번 feature 반영 후 provider 중립적 표현으로 개정이 필요함. S1-4·S5는 이미 provider 중립적 문구라 수정 대상이 아님 (plan.md에서 처리)
